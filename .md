### flask构建
```
docker build -t flaskapp:test .
docker run  -d --name flaskapp-service --network dockernet -p 5000:5000  -v "$(PWD)/logs:/var/log"  -v "$(PWD)/results:/app/application/services/dccl_simulation/results" flaskapp:test 
```

### vue构建
```
docker build -t vueapp:test .
docker run -d  --name vueapp-service --network dockernet -p 8080:8080 -v "$(PWD)/nginx.conf:/etc/nginx/conf.d/default.conf:ro" vueapp:test
```
